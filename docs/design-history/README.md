# Design history

- **2026-09-06 — Phase 2.5A Design Lab.** Three prototype directions (A Quiet Premium, B Smart Bento, C Insight First)
  were built behind a development-only route and compared. Direction A's hierarchy (typography-led balance hero,
  three-column summary, section headers instead of stacked cards) was chosen as the base; C's insight and budget-impact
  ideas were folded in. The two kept captures show the winning prototype before the production rebuild.
- **2026-09-07 — Phase 2.5B production rebuild.** The dark prototype palette was replaced by the light-first production
  system (`docs/DESIGN-SYSTEM.md`); production screenshots live in `docs/screenshots-2.5b/`. The lab, its picker, the
  rejected directions and the fixture were removed.
